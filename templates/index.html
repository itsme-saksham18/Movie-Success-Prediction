Algorithm & Machine Learning Specs

Model Architecture & Verification

High-performance hybrid machine learning ensemble combining Random Forest Regressors, Gradient Boosted Decision Trees, Empirical Bayesian prior smoothing, and Cosine Vector nearest neighbors.

1. Feature Engineering

Multi-hot 20-genre vectorization, log1p transformation on audience votes, Bayesian target encoding with empirical smoothing prior (m=2.0) on directors and cast, and interaction terms.

2. Dual Model Ensemble

Stacked 150-estimator Random Forest + Gradient Boosted Regressor optimized with cross-validation, achieving an R² of 0.8363 and mean absolute error of $22.9M.

3. Classification & Neighbors

Multi-class Gradient Boosting classifier for Success Tier categorization (80.5% Accuracy) and Cosine Nearest-Neighbors embeddings for instantaneous historical film comparisons.
